คู่มือระบบสำรองฐานข้อมูลอัตโนมัติและการกู้คืนข้อมูล (DATABASE BACKUP & DISASTER RECOVERY)
================================================================================
ระบบ            : Kumwell HR System
ฐานข้อมูลเป้าหมาย : appkum_ha (บนเซิร์ฟเวอร์โฮสต์)
ความถี่การสำรอง  : อัตโนมัติทุกวัน เวลา 00:00 น. (เที่ยงคืน)
มาตรฐานความปลอดภัย : เข้ารหัสไฟล์ ZIP ด้วยอัลกอริทึม AES-256 Bit
                  สุ่มรหัสผ่านส่งตรงเข้าสู่อีเมลแผนก ICT
                  จัดเก็บใน Private Storage นาน 30 วัน
================================================================================

[1] ภาพรวมระบบ (SYSTEM OVERVIEW)
--------------------------------------------------------------------------------
1. ทำงานอัตโนมัติ 100% (Zero-Touch Automation)
   สำรองข้อมูลอัตโนมัติทุกวันตอนเที่ยงคืน (00:00 น.) ผ่าน Laravel Task Scheduler

2. รองรับโฮสต์จริงทุกประเภท (Hosting-Ready)
   ใช้เอนจิน PDO Native Streaming ไม่ต้องพึ่งพาโปรแกรมภายนอก (mysqldump)
   ทำงานได้สมบูรณ์บน cPanel, DirectAdmin, Cloud VPS ทั้ง Linux และ Windows

3. การเข้ารหัสระดับทหาร (Military-Grade AES-256 Encryption)
   ไฟล์สำรอง .zip ถูกเข้ารหัสด้วย AES-256 หากไม่มีรหัสผ่านจะไม่สามารถเปิดดูหรือแตกไฟล์ได้

4. สุ่มรหัสผ่านอัตโนมัติ (High-Entropy Random Password)
   รหัสผ่านถูกสุ่มใหม่ทุกวัน ไม่ซ้ำกัน (เช่น KM#xK9$204@bY2) ป้องกันการสุ่มเจาะ

5. ส่งรหัสผ่านตรงเข้าอีเมลแผนก ICT พร้อมแนบคู่มือ .txt
   ทันทีที่สำรองเสร็จ ระบบจะส่งอีเมลแจ้งเตือน รหัสผ่าน และแนบคู่มือการกู้คืน .txt
   ส่งตรงไปยังอีเมลของทีม ICT (ICT_BACKUP_EMAIL) โดยอัตโนมัติ

6. จัดเก็บแยกส่วนปลอดภัย (Private Storage Isolation)
   จัดเก็บไฟล์ที่: storage/app/private/backups/db/
   อยู่นอกโฟลเดอร์ public_html บุคคลภายนอกไม่สามารถเข้าถึงผ่าน URL หน้าเว็บได้

7. นโยบายหมุนเวียนไฟล์ 30 วัน (30-Day Retention Policy)
   ระบบจะลบไฟล์สำรองเก่าที่เกิน 30 วันอัตโนมัติ เพื่อประหยัดพื้นที่ดิสก์บนโฮสต์

[2] รูปแบบการตั้งชื่อไฟล์ (NAMING CONVENTIONS)
--------------------------------------------------------------------------------
1. ไฟล์สำรองบีบอัด (Encrypted ZIP)
   รูปแบบ: backup_db_{DATABASE}_{YYYYMMDD_HHIISS}.zip
   ตัวอย่าง: backup_db_appkum_ha_20260930_000000.zip
   (รองรับเปิดด้วยโปรแกรม WinRAR หรือ 7-Zip บน Windows ทันที)

2. ไฟล์คู่มือประกอบ (.txt Guide)
   รูปแบบ: backup_db_{DATABASE}_{YYYYMMDD_HHIISS}_README.txt
   ตัวอย่าง: backup_db_appkum_ha_20260930_000000_README.txt
   (ดับเบิ้ลคลิกเปิดอ่านได้ด้วยโปรแกรม Notepad ทันที)

3. ไฟล์ฐานข้อมูลภายใน ZIP
   รูปแบบ: database_{DATABASE}_{YYYYMMDD_HHIISS}.sql
   ตัวอย่าง: database_appkum_ha_20260930_000000.sql

4. ไฟล์ข้อมูลสรุปภายใน ZIP
   รูปแบบ: README.txt และ manifest.json
   (บรรจุสรุปรายการตาราง สถิติ และวิธีใช้งานอยู่ภายใน ZIP)

[3] ขั้นตอนการเปิดไฟล์และกู้คืนข้อมูล (HOW TO DECRYPT & RESTORE)
--------------------------------------------------------------------------------
เมื่อเกิดเหตุฉุกเฉินและต้องการนำไฟล์สำรองมาใช้งาน ให้ปฏิบัติตามขั้นตอนนี้:

ขั้นตอนที่ 1: รับรหัสผ่านจากอีเมลแผนก ICT
  1. ค้นหาอีเมลจากระบบ หัวข้อ:
     "🔒 [Kumwell ICT] รหัสผ่านสำรองฐานข้อมูลประจำวัน (AES-256) - backup_db_appkum_ha_..."
  2. ดูรหัสผ่านในกล่อง "AES-256 Decryption Password"
  *(หมายเหตุ: กรณีขอรหัสผ่านผ่านหน้าเว็บ ผู้ใช้งานต้องล็อกอินยืนยันตัวตนด้วย Microsoft 365 และผ่านการตรวจสอบว่าเป็นเจ้าหน้าที่แผนก ICT เท่านั้น เมื่อกดขอรหัสผ่าน ระบบจะจัดส่งรหัสผ่านถอดรหัส AES-256 พร้อมไฟล์คู่มือกู้คืนข้อมูล .txt ตรงเข้าสู่อีเมล Microsoft ของผู้ขอทันที และมีการบันทึกประวัติความปลอดภัย Audit Log)*

ขั้นตอนที่ 2: การถอดรหัสและแตกไฟล์ (WinRAR / 7-Zip / Command Line)

  >> วิธีบน Windows (ผ่าน WinRAR หรือ 7-Zip):
     1. คลิกขวา หรือ ดับเบิ้ลคลิกที่ไฟล์ backup_db_appkum_ha_....zip
     2. หากใช้ WinRAR: เลือก Extract to ... (หรือ Extract Here)
     3. โปรแกรมจะแสดงหน้าต่างถามรหัสผ่าน "Enter password"
     4. กรอกรหัสผ่านที่ได้รับจากอีเมล ICT แล้วคลิก OK
     5. จะได้ไฟล์ database_appkum_ha_....sql ออกมาสมบูรณ์

  >> วิธีบน Linux / VPS (ผ่าน Command Line):
     # ใช้คำสั่ง 7z (แนะนำ)
     7z x -p"<PASSWORD>" backup_db_appkum_ha_20260930_000000.zip

     # หรือใช้คำสั่ง unzip
     unzip -P "<PASSWORD>" backup_db_appkum_ha_20260930_000000.zip

ขั้นตอนที่ 3: นำไฟล์ SQL กลับเข้าสู่ฐานข้อมูล (Database Import)

  >> นำเข้าผ่าน Command Line บนโฮสต์:
     mysql -h localhost -u [DB_USERNAME] -p appkum_ha < database_appkum_ha_20260930_000000.sql

  >> หรือนำเข้าผ่าน phpMyAdmin:
     1. ล็อกอินเข้า phpMyAdmin บนโฮสต์
     2. เลือกฐานข้อมูล appkum_ha
     3. ไปที่แท็บ "Import" (นำเข้า)
     4. เลือกไฟล์ database_appkum_ha_....sql แล้วกด "Import" / "Go"

ขั้นตอนที่ 4: ตรวจสอบความถูกต้องของไฟล์ (SHA-256 Checksum)
  >> บน Windows PowerShell:
     Get-FileHash -Algorithm SHA256 backup_db_appkum_ha_20260930_000000.zip

  >> บน Linux / macOS:
     sha256sum backup_db_appkum_ha_20260930_000000.zip

[4] การตั้งค่าบนเซิร์ฟเวอร์โฮสต์ (HOSTING CONFIGURATION)
--------------------------------------------------------------------------------
1. ค่าในไฟล์ .env บนโฮสต์
--------------------------------------------------
DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=appkum_ha
DB_USERNAME=ชื่อผู้ใช้งานฐานข้อมูลโฮสต์
DB_PASSWORD=รหัสผ่านฐานข้อมูลโฮสต์

# อีเมลแผนก ICT สำหรับรับรหัสผ่านถอดรหัส AES-256
ICT_BACKUP_EMAIL=ict@kumwell.com

# ระบบ Mail สำหรับจัดส่ง
MAIL_MAILER=smtp
MAIL_HOST=smtp.office365.com
MAIL_PORT=587
MAIL_USERNAME=noreply@kumwell.com
MAIL_PASSWORD=your_mail_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@kumwell.com"
MAIL_FROM_NAME="Kumwell HR System"
--------------------------------------------------

2. การตั้งค่า Cron Job บนโฮสต์ (cPanel / DirectAdmin)
ตั้งเวลาให้ทำงานทุก 1 นาที เพื่อให้ Laravel Schedule ตรวจสอบและรันเวลาเที่ยงคืน:
* * * * * cd /home/username/public_html && php artisan schedule:run >> /dev/null 2>&1

[5] คำสั่ง ARTISAN สำหรับผู้ดูแลระบบ
--------------------------------------------------------------------------------
# สำรองข้อมูลทันที พร้อมล้างไฟล์เก่าเกิน 30 วัน
php artisan db:backup --clean

# สำรองข้อมูลโดยกำหนดระยะเวลาเก็บรักษาเจาะจง (เช่น 60 วัน)
php artisan db:backup --clean --keep=60

# ตรวจสอบตารางงานอัตโนมัติ
php artisan schedule:list

--------------------------------------------------------------------------------
[6] เมนูจัดการบนหน้าเว็บ (ADMIN WEB DASHBOARD)
--------------------------------------------------------------------------------
เข้าใช้งานได้ที่ URL: /backend/database-backups (เมนู: สำรองฐานข้อมูล)

- ปุ่ม "สำรองฐานข้อมูลทันที": สั่งสำรองข้อมูลฉุกเฉินได้ทันทีก่อนอัปเดตระบบ
- ปุ่ม "ล้างไฟล์เกิน 30 วัน": ทำความสะอาดไฟล์สำรองที่หมดอายุ
- ปุ่ม "โหลด ZIP": ดาวน์โหลดไฟล์สำรองที่เข้ารหัส AES-256
- ปุ่ม "คู่มือ .txt": ดาวน์โหลดไฟล์คู่มือและรายงานการกู้คืน (.txt) เปิดด้วย Notepad ได้ทันที
- ปุ่ม "รหัสผ่าน": ยืนยันตัวตนผ่าน Microsoft 365 ตรวจสอบสังกัดแผนก ICT หากผ่านจะแสดงปุ่ม "กดขอรหัสผ่าน" พร้อมบันทึก Security Audit Trail (หากไม่ใช่แผนก ICT จะปฏิเสธการเข้าถึงทันที)
